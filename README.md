# Packet Finder 0.1

## Overview

Packet Finder 0.1 is a Python-based network diagnostic tool designed to help users examine network connectivity and measure basic network performance.

The program uses Windows ping utilities and Python libraries to collect network diagnostic information, calculate latency statistics, measure packet loss, and record results.

Packet Finder also includes basic network traffic monitoring using psutil.

## Features

- **Ping Testing:** Sends ICMP echo requests to an IP address or hostname.
- **Packet Loss:** Calculates the percentage of packets lost during a ping test.
- **Latency Measurements:** Calculates minimum, average, and maximum response times.
- **Jitter Calculation:** Measures the average absolute difference between consecutive latency measurements.
- **TXT Logging:** Records timestamped diagnostic events and results.
- **CSV Logging:** Stores structured diagnostic results for later analysis.
- **Failure Logging:** Records failed ping attempts and their associated error messages.
- **Network Traffic Monitoring:** Measures upload and download traffic over a sampling interval.

## Installation

1. Install Python 3.15.
2. Install psutil:

   `py -m pip install psutil`

3. Download or clone the Packet Finder repository.
4. Open the project directory.

## Usage

Run the Python script:

`python "Packet Finder 0.1.py"`

Alternatively, double-click:

`Launch Packet Finder.bat`

Follow the prompts to enter a server IP address or hostname and specify the number of ping requests.

## Output Files

Packet Finder generates two logging files:

**Packet Finder.txt**

Contains timestamped diagnostic events, successful ping results, network traffic measurements, and error messages.

**Packet Finder.csv**

Contains structured diagnostic records, including:

- Timestamp
- Target
- Packets sent
- Packets received
- Packets lost
- Packet loss percentage
- Minimum latency
- Average latency
- Maximum latency
- Jitter
- Status
- Error

## Important Notes

- Network traffic measurements are based on cumulative network interface counters provided by psutil.
- Upload and download measurements may include traffic generated by other applications and local network activity.
- Network traffic measurements should not be interpreted as a dedicated internet speed test.
- Ping results depend on network conditions, firewall configurations, and whether the target responds to ICMP requests.
- Some error-handling improvements are still under development.
